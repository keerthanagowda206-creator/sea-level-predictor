# Sea Level Predictor

A freeCodeCamp Data Analysis with Python project.

## What it does

`sea_level_predictor.py` analyzes global average sea level change since 1880
(`epa-sea-level.csv`) using Pandas, Matplotlib and SciPy:

- Draws a scatter plot of year vs. sea level
- Adds a line of best fit using all the data, extended to 2050
- Adds a second line of best fit using data from 2000 onward, extended to 2050

## Run

    python main.py

## Requirements

- Python 3
- pandas, matplotlib, scipy
